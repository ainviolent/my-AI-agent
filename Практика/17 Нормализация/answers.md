# День 17 — ответы на контрольные вопросы

1. **Что такое очистка текста?**

   Очистка удаляет заранее определённый мусор из текста.

2. **Что такое нормализация текста?**

   Нормализация приводит текст к единообразной записи.

3. **Почему очистка важна для RAG?**

   Меньше мусора и дублей попадёт в поиск и в запрос модели.

4. **Что делает strip()?**

   strip() удаляет пробельные символы по краям.

5. **Что такое табуляция?**

   Табуляция — символ \t, используемый для выравнивания или отступов.

6. **Что делает replace()?**

   replace() заменяет заданный фрагмент строки другим.

7. **Почему strip() не удаляет лишние пробелы внутри строки?**

   strip() работает только с началом и концом строки.

8. **Как убрать несколько пробелов между словами?**

   Использовать " ".join(text.split()). Для исходного Python-кода такой способ не подходит: исчезнут отступы.

9. **Что делает split() без аргументов?**

   split() без аргументов делит строку по последовательностям пробельных символов.

10. **Для чего используется join()?**

   join() собирает строки через разделитель.

11. **Что делает splitlines()?**

   splitlines() разделяет текст на отдельные строки.

12. **Как удалить пустые строки?**

   После очистки добавлять только непустые строки.

13. **Что такое точный дубль строки?**

   Точный дубль — полностью одинаковая строка.

14. **Почему нельзя удалять все повторения без проверки?**

   Повтор может быть необходимым по смыслу, особенно в исходном коде.

15. **Что делает lower()?**

   lower() возвращает строку в нижнем регистре.

16. **Почему не всегда стоит приводить весь документ к нижнему регистру?**

   Регистр нужен для имён, аббревиатур и программного кода.

17. **Что такое неразрывный пробел?**

   Неразрывный пробел — символ U+00A0, препятствующий переносу между словами.

18. **Зачем сравнивать объём текста до и после?**

   Чтобы оценить объём удалённого мусора и заметить чрезмерную очистку.

19. **Как вычислить процент сокращения?**

   (до - после) / до * 100, если исходный объём больше нуля.

20. **Почему после очистки нужно визуально проверить несколько документов?**

   Автоматические правила могут удалить важные данные; нужна проверка смысла.

21. **Что должна делать normalize_text()?**

   Очищать пробелы, пропускать пустые строки и заранее определённые служебные пометки, удалять точные дубли.

22. **Что будет следующим этапом после нормализации корпуса?**

   Разбиение нормализованных документов на чанки.
