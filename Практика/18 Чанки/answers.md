# День 18 — ответы на контрольные вопросы

1. **Что такое чанк?**

   Чанк — небольшой фрагмент документа.

2. **Зачем документы делят на чанки?**

   Чтобы находить и передавать модели только подходящие части.

3. **Что такое chunk_size?**

   chunk_size задаёт максимальную длину фрагмента.

4. **Почему слишком маленький чанк может быть плохим?**

   Слишком маленький фрагмент теряет смысл и контекст.

5. **Почему слишком большой чанк может быть плохим?**

   Слишком большой содержит лишние сведения и занимает контекст модели.

6. **Что такое overlap?**

   overlap — повторяющаяся часть соседних фрагментов.

7. **Зачем нужно перекрытие?**

   Перекрытие частично сохраняет смысл на границе.

8. **Как вычисляется step?**

   step = chunk_size - overlap.

9. **Почему overlap должен быть меньше chunk_size?**

   Иначе шаг будет нулевым или отрицательным.

10. **Что произойдёт, если step равен 0?**

   range() с нулевым шагом вызовет ValueError.

11. **Как получить фрагмент строки через срез?**

   text[start:start + chunk_size].

12. **Что делает range() в алгоритме чанкинга?**

   range() даёт начальные позиции фрагментов с выбранным шагом.

13. **Для чего используется strip()?**

   strip() удаляет пробельные символы по краям чанка.

14. **Почему не стоит сохранять пустые чанки?**

   Пустые фрагменты не несут информации.

15. **Зачем нужен minimum_length?**

   minimum_length позволяет отбрасывать слишком короткие фрагменты.

16. **Что такое source?**

   source хранит имя исходного документа.

17. **Что такое chunk_id?**

   chunk_id — номер фрагмента внутри документа.

18. **Для чего используется enumerate()?**

   enumerate() возвращает номер и элемент при переборе.

19. **Зачем хранить длину чанка?**

   Для проверки размера и сводки по корпусу.

20. **Что делает Path.stem?**

   Path.stem возвращает имя без расширения.

21. **Зачем визуально проверять соседние чанки?**

   Чтобы убедиться, что фрагменты читаются и перекрытие работает.

22. **Почему сегодня размер считается в символах, а не токенах?**

   Символы проще считать на начальном этапе; токены зависят от токенизатора модели.

23. **Что будет следующим этапом после чанкинга?**

   Преобразование чанков в эмбеддинги и поиск по смыслу.
