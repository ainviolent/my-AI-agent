Циклы for и while в Python
Цикл for повторяет действие для каждого элемента последовательности.
Чтобы вывести числа от 1 до 5, напиши for i in range(1, 6): и с отступом print(i).
Правая граница range() не включается. range(5) даёт числа 0, 1, 2, 3, 4.
Цикл while повторяется, пока его условие истинно. Внутри нужно менять данные, от которых зависит условие.
