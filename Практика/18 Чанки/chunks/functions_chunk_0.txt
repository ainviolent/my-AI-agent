Функции в Python
Функция объединяет несколько действий под одним именем, чтобы не повторять код.
Для объявления используют def, имя функции, круглые скобки и двоеточие. Тело пишут с отступом.
Параметры — имена в объявлении функции. Аргументы — конкретные значения при её вызове.
Пример: def square(number): и с отступом return number * number. Вызов square(4) вернёт 16.
