Условия if в Python
Условие if выбирает действие в зависимости от логического выражения.
После условия ставят двоеточие. Тело условия записывают с отступом в четыре пробела.
Пример: если age >= 18, можно вывести сообщение о совершеннолетии.
Ветка else выполняется, когда условие if ложно. У else нет собственного условия.
Для нескольких вариантов используют elif. Проверки идут сверху вниз до первого
