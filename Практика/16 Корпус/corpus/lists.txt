  Списки в Python  

Список хранит несколько значений в одном объекте. Создать список можно квадратными скобками: numbers = [1, 2, 3].
Пустой список создаётся записью items = [] или вызовом list(). В список можно добавлять новые элементы.
Метод append() добавляет один элемент в конец: numbers.append(4).
Индексы начинаются с нуля. numbers[0] возвращает первый элемент, numbers[-1]	—  последний.
Функция len(numbers) возвращает количество элементов списка.
Для перебора списка используют for number in numbers: и тело цикла с отступом.
Элементы списка можно изменять: numbers[0] = 10 заменяет первый элемент.
Срез numbers[1:3] возвращает элементы с индексами 1 и 2. Правая граница не входит в результат.
Если индекс выходит за границы списка, возникает IndexError. Перед обращением проверь длину списка.
