  Ошибки и файлы в Python  

Исключение	—  сигнал об ошибке во время выполнения программы. Например, int("abc") вызывает ValueError.
Потенциально ошибочное действие помещают в try. Обработку конкретной ошибки записывают после except ValueError as error:.
Пользователю показывают понятное сообщение, например Введите целое число, вместо длинной трассировки.
Для технических событий используют logging. INFO означает обычное событие, WARNING — предупреждение, ERROR — ошибку.
Ключ API и содержимое .env нельзя печатать, записывать в журнал или загружать на GitHub.
Файл читают через Path("notes.txt").read_text(encoding="utf-8"). Класс Path находится в pathlib.
Для записи текста используют path.write_text(text, encoding="utf-8"). Кодировка UTF-8 сохраняет русский текст.
Конструкция with open(...) закрывает файл после завершения блока, в том числе при ошибке.
Отсутствующий файл вызывает FileNotFoundError. Сначала проверь путь и существование файла.
