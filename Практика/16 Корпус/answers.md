# День 16 — ответы на контрольные вопросы

1. **Что такое RAG?**

   RAG — поиск материалов с последующей передачей найденного контекста языковой модели.

2. **Зачем RAG использует внешние документы?**

   Чтобы отвечать по конкретной базе знаний, в том числе по новым материалам.

3. **Что такое корпус документов?**

   Корпус — набор тематически связанных документов.

4. **Что такое отдельный документ?**

   Документ — один самостоятельный текстовый источник.

5. **Что такое источник?**

   Источник — происхождение текста, например имя TXT-файла.

6. **Что такое метаданные?**

   Метаданные описывают текст: имя файла, тему, номер фрагмента.

7. **Почему важно сохранять имя источника?**

   Чтобы показать происхождение ответа и проверить его.

8. **Почему корпус должен соответствовать одной задаче?**

   Единая тема уменьшает количество нерелевантных результатов.

9. **Почему качество документов важно?**

   Ошибочный и случайный текст приводит к плохим ответам.

10. **Для чего используется Path?**

   Path представляет путь к файлу или папке.

11. **Что делает glob()?**

   glob() находит файлы по шаблону.

12. **Что означает шаблон *.txt?**

   Любое имя с расширением .txt.

13. **Что делает read_text()?**

   read_text() читает файл в строку.

14. **Для чего указывается encoding='utf-8'?**

   UTF-8 позволяет правильно прочитать русский текст.

15. **Зачем хранить source и text в одном словаре?**

   Чтобы текст не потерял связь с источником.

16. **Что делает strip()?**

   strip() удаляет пробельные символы по краям.

17. **Что делает splitlines()?**

   splitlines() разбивает строку на строки документа.

18. **Для чего используется join()?**

   join() соединяет строки выбранным разделителем.

19. **Почему пустые документы нужно обнаруживать?**

   В пустом документе нет полезной информации для поиска.

20. **Зачем проверять длину документов?**

   Короткий текст может быть неполным или ошибочно загруженным.

21. **Что делает mkdir(exist_ok=True)?**

   Создаёт папку и не вызывает ошибку, если она уже существует.

22. **Что делает write_text()?**

   write_text() записывает строку в файл.

23. **Зачем сохранять очищенную копию корпуса?**

   Чтобы сохранить исходник и отдельно использовать подготовленную версию.

24. **Что будет следующим этапом после подготовки корпуса?**

   Более подробная нормализация, затем разбиение на чанки.
