Функции в Python
Функция объединяет несколько действий под одним именем, чтобы не повторять код.
Для объявления используют def, имя функции, круглые скобки и двоеточие. Тело пишут с отступом.
Параметры	—  имена в объявлении функции. Аргументы — конкретные значения при её вызове.
Пример: def square(number): и с отступом return number * number. Вызов square(4) вернёт 16.
Оператор return возвращает результат и завершает выполнение функции.
Если return отсутствует, функция возвращает None. print() выводит текст, но не заменяет return.
Переменная, созданная внутри функции, обычно доступна только внутри неё: это локальная переменная.
Значение параметра по умолчанию задают в объявлении, например def greet(name="друг").
Чтобы вызвать функцию, нужно написать её имя с круглыми скобками и передать аргументы.
