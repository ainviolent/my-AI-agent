Переменные и типы данных Python
Переменная хранит значение. Запись name = "Илья" связывает имя name со строкой.
Целые числа имеют тип int, дробные числа	—  float, строки — str, логические значения — bool.
Чтобы узнать тип значения, используют type(). Например, type(5) возвращает int.
Функция print() выводит значения на экран. Например, print("Привет") выводит Привет.
Функция input() читает введённую строку. Даже если ввести 5, результат input() будет строкой.
Для преобразования введённого числа применяют int(input()). Если введено не число, возникнет ValueError.
Имя переменной должно быть понятным: age для возраста, total для суммы. Нельзя начинать имя с цифры.
Оператор = присваивает значение. Оператор == сравнивает два значения и возвращает True или False.
