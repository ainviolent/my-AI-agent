# День 19 — ответы на контрольные вопросы

1. **Что такое embedding?**

   Эмбеддинг — числовое представление текста, полученное моделью.

2. **Что такое вектор?**

   Вектор — упорядоченный набор чисел.

3. **Почему тексты превращают в числа?**

   С числовыми представлениями удобно вычислять сходство.

4. **Зачем embeddings нужны в RAG?**

   Чтобы сравнить вопрос с фрагментами и найти контекст.

5. **Что такое similarity?**

   Similarity — числовая оценка близости объектов.

6. **Что такое cosine similarity?**

   Косинусное сходство сравнивает направления векторов.

7. **Почему похожие по смыслу тексты могут иметь высокий score?**

   Модель обучена располагать близкие по смыслу тексты ближе друг к другу.

8. **Что делает model.encode()?**

   model.encode() превращает один текст или набор текстов в эмбеддинги.

9. **Что означает размерность embedding?**

   Размерность — количество чисел в векторе.

10. **Почему embeddings одной модели имеют одинаковую размерность?**

   Выход выбранной модели имеет фиксированную длину.

11. **Как получить embedding нескольких текстов?**

   Передать список строк в model.encode(texts).

12. **Что делает model.similarity()?**

   model.similarity() вычисляет оценки сходства векторов.

13. **Почему текст очень похож на самого себя?**

   Для одинаковых ненулевых векторов косинусное сходство равно единице.

14. **Как сравнить вопрос со всеми чанками?**

   Получить вектор вопроса и вычислить сходство с каждым вектором чанка.

15. **Для чего используется max()?**

   max() находит наибольшее значение.

16. **Как получить индекс максимального score?**

   best_index = scores.index(max(scores)).

17. **Зачем сохранять source?**

   Для проверки происхождения найденного текста.

18. **Зачем сохранять chunk_id?**

   Для различения фрагментов одного источника.

19. **Почему embeddings чанков лучше не пересчитывать для каждого вопроса?**

   Чтобы не тратить время на повторную векторизацию неизменившегося корпуса.

20. **Почему нельзя смешивать embeddings разных моделей?**

   У разных моделей разные пространства признаков; даже одинаковая длина не делает их совместимыми.

21. **Что такое semantic search?**

   Semantic search — поиск по близости смысла в представлении модели.

22. **Почему лучший по score чанк не всегда содержит правильный ответ?**

   Поиск выбирает лучший из имеющихся фрагментов, даже если нужных сведений нет; нужна проверка порога и содержания.

23. **Что такое top-k?**

   Top-k — несколько результатов с наибольшим сходством.

24. **Что будет следующим этапом после создания embeddings?**

   Сохранение векторов и получение контекста для ответа LLM; в итоговом агенте эти этапы связаны.
