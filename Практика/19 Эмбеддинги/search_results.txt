Вопрос: Как создать список в Python?
Источник: lists.txt
Чанк: 0
Текст: Списки в Python
Список хранит несколько значений в одном объекте. Создать список можно квадратными скобками: numbers = [1, 2, 3].
Пустой список создаётся записью items = [] или вызовом list(). В список можно добавлять новые элементы.
Метод append() добавляет один элемент в конец: numbers.append(4).
Индексы начинаются с нуля. numbers[0] возвращает первый элемент, numbers[-1] — последний.

Вопрос: Для чего нужен return?
Источник: functions.txt
Чанк: 1
Текст: return number * number. Вызов square(4) вернёт 16.
Оператор return возвращает результат и завершает выполнение функции.
Если return отсутствует, функция возвращает None. print() выводит текст, но не заменяет return.
Переменная, созданная внутри функции, обычно доступна только внутри неё: это локальная переменная.
Значение параметра по умолчанию задают в объявлении, например def greet(name="друг").
