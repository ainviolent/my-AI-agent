lists.txt 0 Списки в Python

Пустой список создаётся записью items = [] или вызовом list(). В список можно добавлять новые элементы.
Метод append() добавляет один элемент в конец: numbers.append(4).
Индексы начинаются с нуля. numbers[0] возвращает первый элемент, numbers[-1] — последний.

Цикл for повторяет действие для каждого элемента последовательности.
