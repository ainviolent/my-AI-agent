## Запуск

Нужен Python 3.12. Откройте терминал в корне репозитория.

```bash
cd "мой проект"
python3.12 -m venv .venv312
source .venv312/bin/activate
python -m pip install -r requirements.txt
```

В Windows окружение включается командой `.venv312\Scripts\activate`. Далее команды одинаковые.

Скопируйте `.env.example` в `.env` рядом с `main_before_day13.py`. Впишите свой ключ GigaChat после `GIGACHAT_CREDENTIALS=`. Для личного аккаунта оставьте `GIGACHAT_SCOPE=GIGACHAT_API_PERS`. Ключ вводится только в локальном файле.

```bash
python main_before_day13.py
```

При первом запуске загружается модель для поиска по смыслу. Для ответа GigaChat нужны интернет, действующий ключ и доступный лимит API. Отдельно проверить поиск по методичке, без генерации ответа GigaChat:

```bash
python "../Практика/19 Эмбеддинги/final_day19.py"
```

Команды в диалоге: `история`, `очистить`, `выход`. В контекст передаются три последние пары вопрос–ответ. История на диске хранится отдельно в `chat_history.txt`.

## Как обновить базу знаний

Отредактируйте учебные TXT-файлы в [исходном корпусе](Практика/16%20Корпус/corpus). Из папки «мой проект» выполните по порядку:

```bash
python "../Практика/16 Корпус/final_day16.py"
python "../Практика/17 Нормализация/final_day17.py"
python "../Практика/18 Чанки/final_day18.py"
python "../Практика/19 Эмбеддинги/final_day19.py"
```

Последняя команда пересоздаёт индекс и открывает поиск. Проверьте три вопроса и введите `выход`. После этого можно снова запускать `main_before_day13.py`.

В учебных материалах выбран простой способ разбиения по символам. Поэтому граница фрагмента иногда проходит внутри предложения. Эмбеддинги помогают выбрать близкий фрагмент, но не гарантируют правильность ответа. Если сведений нет, помощник просит уточнить вопрос. Порог сходства — 0.35; его можно изменить в `Search.find()`.
