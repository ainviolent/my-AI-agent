# Проверка зависимостей

## Среда выполнения

Ubuntu 24.04.5 LTS в VirtualBox, Python 3.12.3, окружение `УП01/AI-Agent/.venv`, файл `УП01/AI-Agent/requirements.txt`. До установки в окружении был только `pip 24.0`.

## Реестр библиотек

| Библиотека | Для чего нужна | Установленная версия | Есть в `requirements.txt`? |
|---|---|---|---|
| `gigachat` | Вызов GigaChat | 0.2.3 | Да |
| `python-dotenv` | Настройки из `.env` | 1.2.4 | Да |
| `pydantic` | Схема `LessonAnswer` | 2.14.4 | Да, диапазон |
| `sentence-transformers` | Поиск по эмбеддингам | 3.4.1 | Да |
| `transformers` | Модель и токенизатор | 4.46.3 | Да |
| `torch` | Выполнение модели эмбеддингов | 2.2.2+cpu | Да, `2.2.2` |
| `numpy` | Массивы для поиска и работы библиотек | 1.26.4 | Да |
| `huggingface-hub` | Загрузка и кэширование модели | 0.36.2 | Да, диапазон |
| `scikit-learn` | Метрика сходства во вспомогательной функции `retrieval.py` | 1.9.1 | Нет, установлен как зависимость `sentence-transformers` |

## Обнаруженные расхождения

На Linux обычная команда установки начала загружать пакет `torch` на 755,5 МБ и выбрала библиотеки NVIDIA CUDA. Для этой ВМ подходит вариант CPU. Первая загрузка была остановлена до установки.

## Исправления и оставшиеся проблемы

Сначала установлена CPU-сборка той же версии из официального индекса PyTorch, затем повторена команда `pip install -r requirements.txt`. `pip check` вывел `No broken requirements found.` Исходные требования сохранены. Список установленных пакетов не подставлялся вместо `requirements.txt`.

Если вспомогательная метрика будет использоваться отдельно, стоит явно указать `scikit-learn` в требованиях и отдельно проверить этот сценарий.
