# Проверка работоспособности

## Условия

Агент «Объяснение Python». Ubuntu 24.04.5 LTS в VirtualBox, Python 3.12.3. Проверка от 20.11.2026. Команда запуска `.venv/bin/python main.py` из `УП01/AI-Agent`. В первый запуск модель поиска загрузилась в кэш. В среде нет ключа GigaChat.

## Обнаруженные ошибки

При содержательных вопросах программа пишет: «Не удалось получить ответ. Проверьте ключ, доступ к API и подключение». Ветка генерации проверяет `GIGACHAT_CREDENTIALS`, которого в этой среде нет. По сообщению нельзя сделать вывод о доступности API у поставщика, поскольку запрос с ключом не отправлялся.

Отдельный вызов `Search.find` подтвердил поиск. На вопрос про список первым найден `lists.txt` со сходством 0,690. На вопрос про цикл первым найден `loops.txt` со сходством 0,536. Журнал приложения записал `ValueError` без HTTP-статуса для двух попыток генерации.

## Общий итог

Пройдены 3 теста, 2 не пройдены, не выполненных тестов нет. Для полной проверки ответа и истории успешных обменов нужен действующий ключ GigaChat. Локальные сценарии и запуск доступны.
