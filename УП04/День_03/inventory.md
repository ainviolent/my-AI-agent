# Инвентаризация ИИ-агента

## 1. Паспорт проекта

**Название** — «Объяснение Python».  
**Назначение** — помощь начинающим в изучении Python.  
**Основные функции** — поиск по учебному справочнику, объяснение с примером и заданием, ведение истории, просьба прислать код, если его забыли приложить.  
**Файл запуска** — `main.py`, который вызывает `main()` из `main_before_day13.py`.  
**Язык и версия** — Python 3.12.3 в Ubuntu 24.04.5 LTS.  
**Дата проверки** — 20.11.2026.

## 2. ИИ-компоненты

По умолчанию генерацию выполняет `GigaChat-2` от Сбера через внешний API. Модель можно задать через `GIGACHAT_MODEL`. В `main_before_day13.py` SDK `gigachat` вызывает `chat_parse`, а схема `LessonAnswer` описывает поля ответа.

Поиск использует `sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2`. Он работает локально после загрузки модели и возвращает до трёх фрагментов с оценкой от 0,35. В индексе 18 фрагментов из шести файлов с учебными темами, длина каждого вектора — 384. Найденные фрагменты добавляются к системному промпту из `prompts.py`. Агент хранит до трёх последних пар сообщений в контексте и дописывает историю в файл. По найденному коду базы данных и исполнения присланных программ нет.

| № | Компонент | Тип | Назначение | Версия | Расположение |
|---|---|---|---|---|---|

## 4. Реестр файлов

## 5. Внешние сервисы и настройки

GigaChat нужен для генерации ответа. При первом запуске Hugging Face нужен для загрузки модели поиска, если локальной копии и кэша ещё нет. Основной код читает `GIGACHAT_CREDENTIALS`, `GIGACHAT_SCOPE`, `GIGACHAT_MODEL` и необязательный `GIGACHAT_CA_BUNDLE_FILE`. По умолчанию сертификат берётся из `certs/`.

## 6. Неустановленные сведения

Версия сервера GigaChat и доступность конкретной модели для учётной записи определяются у поставщика. Название из настроек показывает, какую модель запрашивает программа.

## Проверка безопасности

Настройки подключения агент читает из окружения и локального `.env`. В исходной проверенной копии присутствовал только `.env.example`. В образце указаны четыре фактически используемые переменные с пустыми значениями. В корневой `.gitignore` добавлены исключения для локального `.env`, окружений, кэша, ключей, журнала и истории диалога.

В текущем дереве открытой ветки `main` есть учебный журнал, пример истории и документы с персональным именем. В новый комплект для публикации эти данные не включаются. Отсутствие рабочего `.env` в дереве ветки само по себе не описывает полную историю Git. Если ключ оказался в истории, его нужно заменить у поставщика. В отчёте значения ключей не приводятся.
