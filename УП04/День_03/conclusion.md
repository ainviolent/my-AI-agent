# Техническое заключение

## 1. Сведения о проекте

«Объяснение Python» помогает начинающим изучать Python. Проверка выполнена 20.11.2026 в Ubuntu. [Репозиторий проекта](https://github.com/ainviolent/my-AI-agent)

## 2. Результаты инвентаризации

В реестре восемь основных компонентов. Локальная MiniLM ищет фрагменты в индексе, затем GigaChat-2 через SDK формирует учебный ответ. `requirements.txt` установлен в `.venv`, `pip check` не обнаружил конфликтов.

## 3. Диагностика

Три теста из пяти пройдены. Пустой ввод и запрос о проверке кода обработаны правильно. Две проверки полного ответа не пройдены, потому что в ВМ не задан ключ. Не выполненных тестов нет.

## 4. Документация

В README агента указаны актуальная папка, точка запуска `main.py`, команды для Ubuntu и Windows, порядок настройки и ограничения. Проверенные команды Ubuntu приведены в аудите документации.

## 5. Риски

| Риск | Возможное последствие | Действие техника |
|---|---|---|
| Нет рабочего ключа или изменился доступ к API | Агент не выдаёт объяснения на обычные вопросы | Настроить ключ в локальном `.env` и повторить тесты 2 и 3 |
| Кэш MiniLM отсутствует и нет доступа к Hugging Face | Агент не доходит до ввода запроса | Загрузить модель заранее и проверить запуск в нужной среде |
| В логах, истории или отчётах есть личная информация | Сведения попадут в открытый репозиторий | Проверить состав коммита, исключить файлы с личной информацией |

## 6. Итоговый статус

**Готов с ограничениями.** Запуск, поиск и обработка локальных сценариев работают в Ubuntu. Успешный ответ внешнего API ещё предстоит подтвердить.

## 7. Три рекомендации по сопровождению

1. Повторять пять проверок после смены зависимостей или модели.
2. Хранить ключ отдельно от репозитория и проверять содержимое коммитов.
3. После обновления справочника пересобирать индекс и проверять вопросы по изменённым темам.
